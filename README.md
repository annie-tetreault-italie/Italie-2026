# Italie 2026 — Version 3.4

## Nouveautés

- Gestionnaire de réservations enrichi
- Réservations liées automatiquement aux journées par leur date
- Statuts : À réserver, Réservé, Payé, À confirmer, Annulé
- Heure, prix, devise, confirmation, lien et notes
- Recherche et filtre par statut
- Résumé du nombre de réservations, des réservations payées et des montants
- Affichage des réservations directement dans la fiche de chaque journée
- Synchronisation Firebase conservée dans `italie/appState`

## Publication

Remplacer les fichiers de la version précédente dans GitHub en conservant :

```
index.html
README.md
css/style.css
js/app.js
```
