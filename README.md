# Mon Carnet de Voyages — Module Photos

Ajoute jusqu’à 3 photos compressées par journée. Les photos sont enregistrées dans la fiche Firebase de la journée et visibles dans Souvenirs.

# Mon Carnet de Voyages — Module Souvenirs

Ajoute un journal, une humeur et un coup de cœur à chaque journée. Les souvenirs sont enregistrés dans Firebase dans les documents Days existants.


Version rating-1.1 : correction de la sélection des étoiles et du cache du fichier JavaScript.


## Position actuelle
Le bouton de localisation utilise la géolocalisation du navigateur sur HTTPS. La position n’est pas enregistrée dans Firebase.
